# Mari Doces 🍰

## Sobre o projeto

Projeto acadêmico desenvolvido em equipe durante o curso de Tecnologia e Dados do Senac, com o objetivo de desenvolver um sistema para auxiliar no gerenciamento de uma confeitaria.

O sistema contempla funcionalidades relacionadas ao cadastro e gerenciamento de clientes e produtos, carrinho de compras e gerenciamento de pedidos.

## Tecnologias utilizadas

- **C#** — desenvolvimento da aplicação
- **MySQL** — criação e gerenciamento do banco de dados
- **Figma** — desenvolvimento e organização visual da interface
- **Visual Studio** — ambiente de desenvolvimento

## Funcionalidades

O sistema foi desenvolvido para auxiliar no gerenciamento de uma confeitaria, contemplando funcionalidades como:

- Cadastro e gerenciamento de clientes;
- Cadastro e gerenciamento de produtos;
- Visualização de produtos;
- Carrinho de compras;
- Gerenciamento de pedidos;
- Integração com banco de dados MySQL.

## Banco de dados

O projeto utiliza **MySQL** para armazenamento e gerenciamento dos dados da aplicação.

O arquivo `BD_MariDoces.sql` contém o script utilizado para criação e configuração do banco de dados.

## Interface e design

Uma das principais áreas de atuação neste projeto foi o desenvolvimento visual da aplicação.

A interface foi planejada considerando a organização dos elementos, identidade visual, imagens dos produtos, ícones e demais recursos gráficos utilizados no sistema.

O design foi desenvolvido utilizando **Figma**, enquanto os recursos visuais utilizados pela aplicação estão organizados no diretório `imagensProjeto/`.
